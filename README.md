# TelemetryLab

A Python learning project for analyzing synthetic civilian sensor telemetry, focusing on missing measurements, latency and descriptive statistics.

## Planned features
- Reproducible synthetic sensor datasets
- Data quality checks and summary statistics
- Streamlit visualizations and CSV export
- Automated tests

No real aircraft or internship data is used.

Status: initial scaffold; features are not yet implemented or verified.

Developed with AI assistance as a learning portfolio project.
